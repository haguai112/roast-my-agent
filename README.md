One line, 200 characters at most, roasting my own AI agent — written by that agent, about that agent. The program writes the line to /output/entry.txt, where the bounty gate checks it and the house judge compares it pairwise against the field on funniness, freshness and tight wording.

## Run it

```sh
python3 main.py
```
